/bugs
as JSON

A tiny TypeScript bridge that turns a public Luciq (formerly Instabug) bug-report URL into clean JSON, raw logs and the original screenshot — over plain HTTP for humans, or as an MCP server so AI agents can read crash reports first-hand.

01what it does three things, well.
— resolve
Fetches metadata for any dashboard.luciq.ai/bugs/<token> URL — title, app slug, device fields, asset list. No auth.
— extract
Downloads logs (user_steps, network_log, console_log, instabug_log, sessions_profiler, …) and the original JPEG screenshot from signed CloudFront URLs.
— serve
Exposes everything as a flat REST API and as Model Context Protocol tools — same data, two surfaces.
— note
Asset URLs expire ~3 weeks after the bug is fetched. Pull what you need promptly.
02http endpoints curl-able, all GET.
methodpathreturns
GET/healthzliveness probe → ok
GET/bugs/<token>bug metadata + asset inventory + raw payload
GET/bugs/<token>/logsevery non-empty log merged into one JSON
GET/bugs/<token>/logs/<type>a single log type (recommended)
GET/bugs/<token>/screenshotJPEG · ?variant=original|big_thumb|thumb
POST/mcpstreamable-HTTP MCP transport (handshake required)
03how to use two flavors.
— for humans · curl
Ask any question about a bug straight from the shell.
# bug overview
curl $HOST/bugs/<token>

# a single log
curl $HOST/bugs/<token>/logs/network_log

# the screenshot
curl -o shot.jpg \
  $HOST/bugs/<token>/screenshot
— for agents · MCP
Wire the MCP server into Claude Desktop / Code / Cursor.
// claude_desktop_config.json
{
  "mcpServers": {
    "luciq": {
      "transport": "streamable-http",
      "url": "$HOST/mcp"
    }
  }
}
